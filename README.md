# WEBTOON Growth Audit

**Live → https://eddieatadapty.github.io/webtoon-flow-rebuild/**

Five ideas to turn more WEBTOON users into subscribers, each built into a clickable version of WEBTOON's own onboarding. Prepared by Adapty.

| # | Idea | Potential outcome |
| :-- | :-- | :-- |
| 01 | Sell WEBTOON Premium at the cliffhanger | +10–20% CR to purchase |
| 02 | Pay off the genre picks right away | +10–15% CR to purchase |
| 03 | Put Premium next to Coins, at the same price | +10–20% CR to purchase, ARPU +3–8% |
| 04 | Turn the ad break into the ad-free offer | +5–10% CR to purchase |
| 05 | Catch the readers who close it | +3–8% CR to purchase |

Every price, rating and feature comes from WEBTOON's App Store listing, website or in-app screens. Impact ranges are Adapty’s expected effect from teardowns and A/B tests across 30,000+ subscription apps, not measured lift for WEBTOON. They overlap, so they don’t add up. The ads layer carries no range: only a test per ad can give one.

Static single page, no build step: `python3 -m http.server`.
